# CICIoT2023 multiclass results

Historical outputs from the standard and class-weighted multiclass trainers.

- `ft_multiclass_test_metrics.json` and `ft_multiclass_train_history.json`: standard run.
- `ft_multiclass_weighted_test_metrics.json` and `ft_multiclass_weighted_history.json`: weighted run.

The task is **7 attack families plus Benign, 8 classes in total**. The historical `7class` path name counts attack families rather than total model outputs. These results were not rerun during repository organization.

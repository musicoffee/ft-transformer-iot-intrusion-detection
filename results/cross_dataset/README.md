# Cross-dataset results

- `ft_binary_cross_dataset_metrics.json`: 8-head FT-Transformer results on the 38-feature aligned main and external tests.
- `cross_dataset_baseline_compare.json`: Random Forest and XGBoost comparisons with recorded sampling settings.

The historical alignment uses each domain's own fitted scaler statistics. Consequently, the CICIoMT2024 result is not strict source-only zero-shot evaluation. Files are original historical outputs and were not regenerated during repository organization.

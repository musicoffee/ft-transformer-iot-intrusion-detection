# Local SHAP artifacts

Historical selected-sample outputs from `analysis/revision_05_local_shap_explanations.py`:

- `local_shap_selected_samples.csv`: sample type, test index, true/predicted label, and attack probability.
- `local_shap_values.csv`: sample type, test index, feature name, standardized feature value, and SHAP contribution.

The files contain no IP addresses, device identifiers, payloads, or full raw traffic records. Feature values are the model-input values used for explanation, not a released dataset sample table.

# Reproducibility tables

Small descriptive tables generated by `analysis/revision_01_make_reproducibility_tables.py`:

- `dataset_split_summary.csv`: recorded train/validation/test sizes.
- `class_distribution_summary.csv`: recorded class counts by split.
- `Table_S1_shared_38_features.csv`: the feature intersection used in the aligned cross-dataset experiment.

These tables contain aggregate descriptions and feature names, not traffic sample rows.
